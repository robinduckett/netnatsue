# Natsuo Default Status Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `NET: WHAT` reports `Natsuo YYYY-MM-DD` (build date) instead of an empty string when the client is idle.

**Architecture:** A build-time-generated `NetBuildDate.h` (CMake custom target + `cmake -P` script with copy-if-different) defines `NETNATSUE_BUILD_DATE`; `DSNetManager.cpp` includes it when the CMake-only `NETNATSUE_BUILD_DATE_HEADER` define is set and otherwise converts `__DATE__`. `DebugGetCurrentAction()` falls back to the composed default when `myCurrentAction` is empty.

**Tech Stack:** C++98-style codebase (tabs, no new includes needed), CMake ≥ 3.10, standalone harness `test/NetNatsueTest.cpp`.

**Spec:** `docs/superpowers/specs/2026-07-13-natsuo-default-status-design.md`

## Global Constraints

- Idle status string is exactly `"Natsuo "` + date in `YYYY-MM-DD` (17 chars); "Natsuo" spelling is intentional.
- Busy strings ("Logging in as …" etc.) unchanged; only the empty-string case gains a fallback.
- Non-CMake builds (compiling the five `.cpp` files directly) must still compile and produce the `__DATE__`-derived date.
- Work lands on the existing `natsue-client-modes` branch (PR robinduckett/netnatsue#1).

Create `cmake/BuildDate.cmake`:

```cmake
# Writes a header defining NETNATSUE_BUILD_DATE (YYYY-MM-DD, UTC).
# Run at build time via cmake -P; copy_if_different keeps the header
# untouched (and dependents unrebuilt) unless the date changed.
string(TIMESTAMP NETNATSUE_BUILD_DATE "%Y-%m-%d" UTC)
file(WRITE "${OUT}.tmp"
	"// Generated by cmake/BuildDate.cmake - do not edit\n"
	"#define NETNATSUE_BUILD_DATE \"${NETNATSUE_BUILD_DATE}\"\n")
execute_process(COMMAND "${CMAKE_COMMAND}" -E copy_if_different
	"${OUT}.tmp" "${OUT}")
file(REMOVE "${OUT}.tmp")
```

In `CMakeLists.txt`, after the `target_include_directories(netnatsue PUBLIC ...)` line:

```cmake
# The idle NET: WHAT status embeds the build date.  Regenerated on
# every build; direct (non-CMake) builds of the sources fall back to
# the compiler's __DATE__ instead.
set(netnatsue_build_date_header
	${CMAKE_CURRENT_BINARY_DIR}/generated/NetBuildDate.h)
add_custom_target(netnatsue-build-date
	COMMAND ${CMAKE_COMMAND} -DOUT=${netnatsue_build_date_header}
		-P ${CMAKE_CURRENT_SOURCE_DIR}/cmake/BuildDate.cmake
	BYPRODUCTS ${netnatsue_build_date_header})
add_dependencies(netnatsue netnatsue-build-date)
target_include_directories(netnatsue PRIVATE
	${CMAKE_CURRENT_BINARY_DIR}/generated)
target_compile_definitions(netnatsue PRIVATE NETNATSUE_BUILD_DATE_HEADER)
```

Replace `DebugGetCurrentAction` (lines 337-340) with a file-static helper plus the fallback:

```cpp
// The idle status: identifies this client and its build date.
// CMake builds generate NetBuildDate.h every build; direct builds of
// the five .cpp files fall back to the compiler's __DATE__
// ("Mmm dd yyyy"), which refreshes when this file recompiles.
static const std::string& DefaultCurrentAction()
{
	static std::string action;
	if (action.empty())
	{
#ifdef NETNATSUE_BUILD_DATE
		action = std::string("Natsuo ") + NETNATSUE_BUILD_DATE;
#else
		const char* date = __DATE__;
		static const char names[] = "JanFebMarAprMayJunJulAugSepOctNovDec";
		int month = 0;
		for (int i = 0; i < 12; ++i)
			if (strncmp(date, names + i * 3, 3) == 0)
				month = i + 1;
		int day = (date[4] == ' ' ? 0 : (date[4] - '0') * 10)
			+ (date[5] - '0');
		char buffer[16];
		nn_snprintf(buffer, sizeof(buffer), "%.4s-%02d-%02d",
			date + 7, month, day);
		action = std::string("Natsuo ") + buffer;
#endif
	}
	return action;
}

std::string DSNetManager::DebugGetCurrentAction()
{
	if (myCurrentAction.empty())
		return DefaultCurrentAction();
	return myCurrentAction;
}
```

Note: check first whether the file defines an `nn_snprintf` (it defines `nn_vsnprintf` for `Log`); if only `nn_vsnprintf` exists, use plain `sprintf(buffer, ...)` — the output is bounded (4+1+2+1+2+1 = 11 chars < 16) and `sprintf` is already used elsewhere in the file.
